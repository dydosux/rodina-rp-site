# RODINA RP — презентационный сайт

Статический лендинг, готовый для GitHub Pages.

## Публикация

1. Создайте новый GitHub-репозиторий и загрузите содержимое этой папки в корень.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и каталог `/ (root)`.
4. Сохраните настройки — GitHub выдаст публичную ссылку.

Локально сайт можно открыть двойным щелчком по `index.html` или через любой статический HTTP-сервер.

Hero-изображение создано специально для этой страницы. Превью дев-блога используют материалы из локального Discord-архива.
